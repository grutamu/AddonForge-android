AddonForge
No internet connection. Checking and installing addons need Wi-Fi.

The catalogue is instawow's public list of addons CurseForge tags for Forever (layday/instawow-data), refreshed daily. Addons with a GitHub repo install from GitHub; the rest install from CurseForge.

WoW install

The product folder AddonForge manages. Only WoW: Forever for now.

Updates

For authors who only ship their Forever build as a GitHub pre-release or a Wago beta. Uses the GitHub API for the check, limited to 60 requests an hour without a token.

Wago key optional

Some addons only publish on Wago. Their API needs a key, free from addons.wago.io. Stored on this device, only ever sent to addons.wago.io.

Addon list

Names and sources only, no settings. Import one to install everything on it.

Report a problem

Builds a report with your version, install folder, addon list and the last few log lines. Nothing is sent until you press send, and you can read it first.


      

    


    

      
About

      

        
AddonForge for Android 

        
An unofficial port of AddonForge by Pocket Forge Studios, who don't make or support this version: please report problems here, not to them. MIT licensed.

        
No accounts, no ads, no analytics. Talks only to the addon sites (GitHub, Wago, WoWInterface, TukUI, CurseForge, and cfwidget.com for CurseForge file lists), plus one request to GitHub at launch to see if AddonForge itself has an update.

Welcome to AddonForge

    

      
AddonForge installs and updates addons in your WoW: Forever game folder.

      
That folder was made by your WoW launcher, so Android needs you to allow All files access. AddonForge only ever changes Interface/AddOns.
